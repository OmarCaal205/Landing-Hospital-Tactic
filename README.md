# Centro Médico Verapaz – Landing Page (React + Vite)

## Cómo usarlo
1. Instala Node.js (https://nodejs.org)
2. Abre la carpeta en Visual Studio Code
3. En la terminal: `npm install` y luego `npm run dev`
4. Abre http://localhost:5173

## Qué editar
- `src/data.js`: teléfono, WhatsApp, dirección, mapa, servicios, equipo y estadísticas
- `public/img/`: logo y fotos (puedes reemplazarlas con el mismo nombre)
- `src/styles.css`: colores (variables `:root`) y estilos
- `src/components/`: cada sección de la página
- Mapa: en Google Maps > Compartir > Insertar un mapa, copia el `src` del iframe en `mapaSrc`
